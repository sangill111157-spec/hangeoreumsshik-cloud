[엔비디아 트레이딩 시스템 - 새 노트북 이전 및 실행 지원 요청]

안녕 GPT! 나는 지금 아내의 점핑클럽에 있는 새 노트북으로 '엔비디아 트레이딩 시스템 서버'를 이전하려고 해.
기존 노트북의 안실장(AI 에이전트)이 필요한 핵심 소스코드와 자동 세팅 배치파일을 'NVDA_Trading_System_NewLaptop.zip'으로 압축해서 USB에 담아왔어.

지금부터 내가 새 노트북에서 이 서버를 완벽하게 구동할 수 있도록 친절하고 쉽게 하나씩 가이드해 줘!

---

### 1. 시스템 정보
- 시스템 명: 엔비디아 자동 트레이딩 시스템 (FastAPI + Uvicorn 백엔드 + KIS 증권 연동 + 텔레그램 알림)
- 백엔드 서버 포트: 8000 (FastAPI: uvicorn app.main:app)
- 프론트엔드 대시보드: React / Vite 기반 (nvda-trading-dashboard)
- 핵심 설정: KIS API 키 및 텔레그램 봇 토큰은 backend/.env 파일에 이미 세팅되어 있음.

### 2. 압축파일 내부 포함 스크립트
1. '1_새노트북_처음설치_및_서버실행.bat' (최초 1회 실행: 파이썬 venv 가상환경 생성 + requirements.txt 라이브러리 자동 설치 + uvicorn 서버 실행)
2. '2_평상시_서버실행.bat' (평상시 서버 재기동용)
3. '3_대시보드_화면_실행.bat' (웹 차트 대시보드 화면용)
4. '[필독]_새_노트북_설치_및_실행방법.txt'

### 3. 내가 진행할 순서 (GPT가 확인해 줄 부분)
1단계: 새 노트북에 Python(3.10~3.12 권장) 설치 확인 ('Add python.exe to PATH' 체크 필수)
2단계: 원하는 위치(예: C:\trading\package\nvda_trading_system)에 압축 해제
3단계: '1_새노트북_처음설치_및_서버실행.bat' 실행 후 포트 8000 서버 정상 기동 확인
4단계: (선택) Node.js 설치 및 대시보드 화면 띄우기

내가 진행하면서 뜨는 터미널 화면이나 에러 메시지를 물어보면 바로바로 해결책을 알려줘!
준비됐으면 내가 1단계부터 시작할 수 있게 첫 번째 단계 안내를 시작해 줘!
